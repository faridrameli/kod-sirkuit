How It Works

🔌 Board View

Every file is a chip. Click one to light up its connections — amber to what it uses, teal from what uses it.

🎯 Flow View

Double-click a chip to play through a function like a game. Every decision stops and waits for you.

⚡ Power On

Start at the entry point and light up everything the code can reach. Spot dead or disconnected code instantly.

🔍 Step Through

Walk through each line with variables shown. See what every decision depends on.
